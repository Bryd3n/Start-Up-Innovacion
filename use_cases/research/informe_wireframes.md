# Informe: Cómo crear un boceto web o wireframe

*Basado en el artículo de Palbin: [Cómo crear un boceto web o wireframe](https://www.palbin.com/es/blog/p1027-como-crear-un-boceto-web-o-wireframe.html)*

## 1. ¿Qué es un wireframe?
Un **wireframe** o boceto web es un esquema visual o plano de una página web. Su propósito es definir la estructura, la disposición del contenido y la funcionalidad a grandes rasgos, sin entrar en detalles gráficos como colores, tipografías o imágenes finales. Actúa como los cimientos de una casa antes de comenzar a construirla y decorarla.

## 2. Elementos que componen un wireframe
Para crear un buen prototipo, se deben tener en cuenta tres aspectos clave del diseño:

*   **Diseño de información:** Consiste en organizar y priorizar la información que se va a mostrar para que cumpla con los objetivos del proyecto. Define qué contenido es más importante y dónde debe colocarse para facilitar la comprensión.
*   **Diseño de navegación:** Define la relación entre los enlaces y las diferentes páginas. El objetivo es crear caminos claros para que el usuario pueda desplazarse por el sitio web de forma intuitiva, encontrando lo que busca sin esfuerzo.
*   **Diseño de interfaz:** Implica seleccionar y ordenar los elementos con los que el usuario va a interactuar (botones de acción, campos de texto, menús desplegables, etc.). Una buena interfaz mejora directamente la usabilidad de la web.

## 3. Ventajas de utilizar wireframes
Aunque pueda parecer un paso extra, realizar un boceto web aporta numerosos beneficios:
*   **Rapidez:** Se pueden crear rápidamente usando diversas herramientas.
*   **Bajo coste:** Permite realizar y descartar varias versiones hasta encontrar la estructura ideal sin un gran gasto.
*   **Detección temprana de errores:** Ayuda a identificar problemas de usabilidad o funcionalidad antes de empezar el desarrollo y diseño final.
*   **Mejora de la experiencia de usuario (UX):** Facilita la realización de pruebas con usuarios (como test A/B en prototipos) para ver cómo reaccionan y navegan.
*   **Ahorro a largo plazo:** Evita tener que rehacer partes de la web una vez ya programadas, ahorrando mucho tiempo y dinero.

## 4. Herramientas y programas recomendados
Existen múltiples opciones para todos los niveles y presupuestos a la hora de hacer un wireframe:

*   **A mano (papel o pizarra):** La opción más rápida y recomendable para las primeras lluvias de ideas.
*   **Adobe Photoshop / Illustrator:** Útiles si ya se tienen conocimientos previos de diseño.
*   **Adobe XD:** Un programa profesional y específico para prototipado, que permite añadir animaciones y compartir los prototipos fácilmente.
*   **Herramientas gratuitas o freemium:**
    *   **MockFlow:** Muy intuitiva y fácil de usar, aunque su versión gratuita limita los proyectos a 4 páginas.
    *   **JustInMind:** De uso más profesional, pero cuenta con una versión gratuita de gran ayuda.
    *   **Canva:** Plataforma muy versátil que ofrece múltiples plantillas para comenzar prototipos web sin coste.
